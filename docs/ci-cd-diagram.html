CI Workflow

Trigger: Push or PR to dev / staging / main
Steps: Checkout → Node 20 → npm ci → Lint → Build
Must pass before merging

ci.yml

Staging Tests

Trigger: Push to staging (or manual)
Steps: Wait 3 min for Vercel → Health check → API tests + Security audit (parallel)
Secrets: STAGING_URL, Supabase keys, bypass token

staging-tests.yml

Production Deploy

Trigger: Push to main
Steps: Wait 60s → HTTP health check → API probe → Pass/fail notification
Vercel auto-deploys main to production

deploy-prod.yml
